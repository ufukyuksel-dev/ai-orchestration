# AI Orchestration

A hook gives you this repository's build profile, rules, matching memory cards and the files the request most likely touches (the block that starts with "AI Orchestration"). Start from them: open those files directly instead of searching, use the profile's commands, and follow the rules. Read only the files you need. Check with the fastest sufficient command (one test class, then the profile's test command once); do not re-run a check that passed unless files changed since. Build and test commands take up to a few minutes: start them with `yield_time_ms: 300000` so you wait for the result once instead of polling. Start the app or call it with curl only when no test can cover the requested behavior. Formatting, test totals and saving what the task taught are handled automatically.
